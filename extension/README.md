# 外部扩展实现

- `renderer.mjs`：临时 iframe、可信闭包通信、静态壁纸、快捷键与完全恢复。不注册永久轮询。
- `payload.mjs`：打包本地 HTML/CSS/图片/动画函数，绑定 iframe 环境；无需修改 CSP 或运行本地资源服务器。
- `cdp.mjs`：主窗口筛选、回环 WebSocket 验证、有限超时和连接清理。
- `run.mjs`：验证 OpenAI 应用签名、随机回环端口和所属进程，启动原应用；确认播放开始后断开连接并退出。
- `wallpaper.css`：按已核对的原生布局属性和颜色变量设置透明表面。
- `Native/Extension.swift`：轻量启动入口，发现已运行的 Codex 时激活其窗口并退出，不重启应用。

不修改官方包，不安装守护进程，不读取聊天内容，不改变 API 配置。CDP 端口随 Codex 存活，关闭扩展层不能关闭端口，需要完全退出并正常重开。

用户已确认实际试用正常；新的适配变更仍需验证，测试页成功不等同于所有实际版本兼容。设置使用 ⌘⌥B，开场不显示设置按钮。面板保留原样式，增加前半段标题、小字及后半段字幕输入，复用原 IndexedDB 记录且兼容旧图片设置。保存成功才重播；关闭或 Esc 直接结束覆盖层、回到主页面，未保存修改不生效。
